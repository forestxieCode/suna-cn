# Kortix Project Guide

## Project Overview
Kortix (Repo: `suna`) is a platform for creating and managing autonomous AI agents. It uses a monorepo structure with a Python FastAPI backend and a Next.js frontend.

## Structure
- `apps/frontend`: Next.js 15 dashboard for managing agents.
- `backend`: main Python FastAPI application (Kortix core).
- `packages`: Shared packages.
- `sdk`: Python SDK.
- `docker-compose.yaml`: Local development infrastructure (Redis, Backend, Frontend).

## Tech Stack
### Frontend (`apps/frontend`)
- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript, React 18
- **Styling**: Tailwind CSS 4, Radix UI, Shadcn UI
- **State**: Zustand, TanStack Query
- **Editor**: CodeMirror, Tiptap
- **Build**: pnpm

### Backend (`backend`)
- **Framework**: FastAPI
- **Language**: Python 3.11+
- **Manager**: `uv` (Universal Python Packaging)
- **Database**: Prisma (ORM), Postgres (via Supabase), Redis
- **AI/LLM**: LiteLLM, OpenAI, Anthropic, Langfuse
- **Tools**: Ruff (linting), Pytest (testing)

### Infrastructure
- **Auth/DB**: Supabase
- **Containerization**: Docker, Docker Compose

## Commands

### Global
- **Setup**: `python setup.py` (Interactive setup wizard)
- **Start All**: `python start.py`

### Backend (`/backend`)
- **Run Dev**: `uv run api.py`
- **Lint**: `make lint` (uses Ruff)
- **Test**: `make test` or `uv run pytest`
- **Verify**: `make verify`

### Frontend (`/apps/frontend`)
- **Install**: `pnpm install`
- **Dev Server**: `pnpm dev` (runs on port 3000)
- **Build**: `pnpm build`
- **Lint**: `pnpm lint`

## Development Guidelines
- **Monorepo**: Uses `pnpm` workspaces.
- **Backend Env**: Managed by `uv`. Dependencies in `pyproject.toml`.
- **Frontend Env**: Next.js App Router structure (`src/app`).
- **Configuration**:
    - Backend: `.env` (managed by setup).
    - Frontend: `.env.local` (managed by setup).

## Key Files
- `setup.py`: Main entry point for project configuration.
- `backend/api.py`: Backend entry point.
- `backend/core/`: Core agent logic.
- `apps/frontend/next.config.ts`: Next.js configuration.
